Metodologia SpinFlow
Uma linguagem única para operar e escalar qualquer empresa.
SpinFlow organiza a operação em 7 níveis hierárquicos claros — do macro ao micro — criando uma linguagem comum entre todos os setores. Serve ao uso próprio e como produto replicável para clientes.

9 Princípios Fundamentais
P01
🔄 Processo > Projeto
Processos evoluem sem parar. Projetos têm fim. Toda modelagem segue a lógica de fluxo recorrente.
P02
↕️ Macro Linear, Micro Fluido
As 5 Fases são roadmap linear. Dentro de cada fase, atividades seguem lógica fluida de SOP.
P03
🚩 Marco como Status
Status é derivado do fechamento real de etapas — não declarado por mão livre.
P04
📋 Atividade é SOP, Tarefa é Execução
Atividade fecha por critério de sucesso. Tarefa é instância concreta e repetível.
P05
📜 Histórico por Loop
Tentativas falhas viram log — nunca apagadas. Nova tarefa é engatilhada. Histórico é sagrado.
P06
⚡ Previsibilidade Engatilhada
Tarefas em loop não são pré-criadas — nascem sob necessidade. Backlog limpo, dado utilizável.
P07
🌐 Universalidade
O mesmo modelo serve a todo setor. Uma linguagem comum para toda a empresa.
P08
🏛️ Composição Setorial
Processos vivem dentro de Setores. Cada Setor evolui independentemente sem impactar os demais.
P09
✅ Sucesso vs. Não-Sucesso
Toda tarefa declara "Concluída-com-sucesso" ou "Concluída-sem-sucesso". Esse binário governa todos os loops.
9 Padrões de Fluxo
P1 — SequencialEtapas · Atividades · Tarefas
B só inicia após A concluir com sucesso. Usar quando há dependência real de output.
[A] ──── concluída ────▶ [B]
P2 — ParaleloEtapas · Atividades
A e B progridem independentemente. Menor lead time, maior coordenação.
┌──▶ [A] ──┐ [start]┤ ├──▶ next └──▶ [B] ──┘
P3 — Marco-libera-FaseTransição Fase → Fase
A Fase N só avança quando todas as Etapas estão concluídas. Mecanismo canônico — sempre ativo.
[Fase N] ├── Etapa N.1 ✓ └── Etapa N.2 ✓ ▼ avança para [Fase N+1]
P4 — Loop de AtividadeTarefas dentro de Atividade
Cada tentativa vira nova Tarefa. A anterior não é reaberta. Histórico íntegro.
Tarefa #1 → sem-sucesso Tarefa #2 → sem-sucesso Tarefa #3 → ✓ sucesso
P5 — Engatilhamento CondicionalTarefas dentro de Atividade
Tarefa N+1 nasce somente se N fecha sem sucesso. Se N tem sucesso, a atividade fecha.
Tarefa N → sucesso? ├─ Sim → Atividade fecha ✓ └─ Não → Engatilha N+1
P6 — Bloqueada por ExternoAtividade
Quando o bloqueio é externo, a Atividade entra em estado Bloqueada com motivo e data registrados.
status: Bloqueada motivo: "aguard. assinatura" desde: 2026-05-07
P7 — Insucesso e CascataAtividade → Etapa
Atividade sem-sucesso pode não impedir a Etapa, engatilhar alternativa, ou fechar como insucesso.
Atividade sem-sucesso ├─ Etapa ok? → Avança ├─ Atividade alt? → Loop └─ Terminal → Aborta
P8 — Derivado de ProcessoProcessos Derivados
Um processo engatilha outro. Comercial ganho → Operacional inicia automaticamente.
Processo A concluído ▼ engatilha Processo B inicia
P9 — Recorrente AutônomoAtividades de Manutenção
Atividade reativada por tempo (semanal, mensal). Não depende de evento externo.
timer: todo domingo 9h ▼ cria Tarefa #N status: A fazer → loop

Linguagem de Empresas Maduras
Equivalências para nomear funções, setores e responsabilidades no SpinFlow.
A intenção é construir primeiro para uso próprio e depois formatar como produto replicável. Esta seção traduz termos internos para conceitos comuns em empresas maiores.
Equivalências de cargos
👑 Dono da Empresa
= CEO / Founder / Managing Director
Direção, prioridades e alocação de recursos. Foco: Estratégia.
⚙️ Gerente Operacional
= COO / Head of Operations
Orquestrar processos, projetos, capacidade e qualidade. Foco: Operação.
🎯 Supervisor de Etapa
= Team Lead / Process Supervisor
Garantir marcos, critérios e outputs. Foco: Controle.
🔨 Time Operacional
= Operators / Specialists / ICs
Executar atividades, tarefas e registros de desfecho. Foco: Execução.
📋 Dono do Processo
= Process Owner
Manter Modelo de Referência, critérios e melhoria contínua. Foco: Governança.
🚀 Gestor de Melhoria
= PMO / Strategy Ops / Business Operations
Transformar gaps em iniciativas e medir impacto. Foco: Evolução interna.
