Como os componentes interagem
📖
Sessão começa
Claude lê CLAUDE.md → importa memory/ → conhece o projeto sem briefing.
⚡
Skill é acionada
Automaticamente quando relevante, ou via "use a skill X" — carrega conhecimento especializado no contexto.
🤖
Agent é invocado
Roda em contexto isolado, investiga profundamente e retorna apenas o resumo — sem poluir a sessão principal.
🔧
Command executa
Sequência completa de passos: coleta info → aciona agents → atualiza ClickUp → registra decisão → confirma.
